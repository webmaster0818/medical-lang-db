### 夜間の実行計画（案）

1. 第1夜〜第2夜：`fetch_list.py --window 22-6 --gap 6` で、23言語×47都道府県の一覧を取り、`list_ids.json`（ID→対応言語）を作ります
2. 第3夜〜：`fetch.py <list_ids.json> data/raw --window 22-6 --gap 6` で施設詳細を取ります。都道府県の順番は、strategy §4-3 の立ち上げ都市（東京・大阪・愛知・埼玉・静岡・群馬・福岡・神奈川・北海道・京都）を先にし、その他を後にします。主要都市は約1週間でそろう見込みです
3. 再開できる作りです。取得済みのファイルは飛ばし、途中で止めても同じコマンドで続きから再開します。中身のないページは `gone.txt` に記録して、以後は飛ばします
4. 止める条件：5回続けて失敗したら停止します（失敗のたびに60秒待ちます）。HTTP 429・503 が出たら間隔を10秒に広げて再開します
5. 毎朝の確認：前夜の取得件数・失敗・中身なしの件数を `fetch_log.tsv` から集計し、このチャンネルに報告します
6. 更新：オープンデータの更新（6月1日・12月1日時点）にあわせて年2回、全件を取り直します。その間は月1回、一覧だけを取り直して増減を反映します（一覧は約14時間＝2晩）
