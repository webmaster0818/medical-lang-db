## 1. 運営者情報（`/{lang}/about/`）

### このサイトについて

このサイトは、日本に住んでいる方と日本を旅行している方が、自分の言語で受診できる医療機関を探すためのデータベースです。厚生労働省の「医療情報ネット（ナビイ）」と、厚生労働省が公表している「外国人患者を受け入れる医療機関」のリストをもとに、医療機関ごとの言語の対応、診療科、受付時間、支払方法をまとめています。

利用は無料です。会員登録は必要ありません。

|---|---|
| サイト名 | MediLingo Japan |
| URL | https://medilingojapan.com/ |
| 運営会社 | 【要記入】 |
| 所在地 | 【要記入】 |
| 代表者 | 【要記入】 |
| 設立 | 【要記入】 |

※先行サイト A は、サイト上の代表者名と会社の公式サイトの代表者名が食い違っていました（saburo-2 第5段階の調査）。当サイトは法人番号を載せ、登記と一致させることを提案します。

### 運営体制

- このサイトは医療機関ではありません。医師・薬剤師による監修は【要決定：現時点では無し】です。**監修者がいない間は「監修」「医師監修」と書きません。**架空の監修者は置きません。
- 掲載している情報は、公的機関が公表しているデータと、各医療機関が都道府県に報告した内容です。当サイトが医療機関を取材・審査・評価したものではありません。
- 診療科・地名は、厚生労働省・自治体・日本政府観光局（JNTO）などが公開している多言語資料を出典にした辞書の訳を使います。辞書に訳がない語は、日本語のまま表示します。
- 言語名・曜日は、Unicode CLDR（国際的な言語データ）の表記を使います。
- 見出し・ボタンなどの画面の文言は、出典のある訳がないため、当サイトが訳したうえで、別々の2系統の点検で全行の確認を受けたものを使います。機械翻訳をそのまま使うことはしません。

### 医療機関との関係

- 現在、医療機関から掲載料・紹介料などの対価は受け取っていません。掲載の有無や並び順は、医療機関からの依頼や支払いでは変わりません。
- 将来、医療機関の有料掲載を始める場合は、そのページに「広告」と表示し、このページで事前にお知らせします（→ 03 確認表 表A・運用ルール5。有料掲載の時点で医療法の広告規制とステマ規制の表示義務がかかります）。

## 2. 編集方針（`/{lang}/editorial-policy/`）

### 基本の考え方

このサイトは、「どの医療機関で、どの言語が、どのような方法で通じるか」を、公的なデータに書かれているとおりに示すことを目的にしています。医療機関の良し悪しを評価したり、特定の医療機関を勧めたりはしません。

### 掲載するもの

- 医療機関の名称（日本語・読み・ローマ字。公式の外国語名がある場合はその表記）、住所、電話番号、地図
- 診療科、診療日・受付時間
- 言語ごとの対応（受入れの可否、対応の方法、対応する曜日・時間、外国語用の電話番号、予約の要否）
- 支払方法（現金・クレジットカードの種類・電子マネー・QRコード決済）
- 救急の体制
- 出典と、データの時点

### 掲載しないもの

- ランキング、点数、「おすすめ」「人気」などの評価
- 口コミ・体験談
- 治療の効果、他の医療機関との比較
- 自由診療の料金、手術の件数、専門医の資格、メディア掲載
- 医療機関が自由記述で書いた内容の翻訳（日本語の原文のまま「原文（日本語）」と表示します）

### 言語の対応の4段階 {#tiers}

医療機関の報告内容をもとに、言語ごとの対応を次の4つに分けて表示します。**これは報告内容の分類で、通訳の質や医療の質を評価したものではありません。**

| 表示 | 名前 | 意味 |
|---|---|---|
| ◎ | この言語で受診可 | その言語で受診できると、医療機関が報告しています。または、その言語の医療通訳者・コーディネーターがいると報告されています |
| ○ | 電話・ビデオ通訳 | その言語は、電話またはビデオの通訳サービスで対応すると報告されています |
| △ | 翻訳機あり | 医療機関に翻訳機があり、その言語は翻訳機で対応すると報告されています |
| ― | 来院前に連絡を | その言語の記載はありますが、通訳・翻訳機の記録がありません。受診する前に、医療機関に連絡してください |

- ◎は「医療機関がそう報告している」という意味です。職員が話すのか、通訳者がいるのかは、元のデータでは区別できません。
- ―の後半「受診する前に、医療機関に連絡してください」は当サイトからの案内で、医療機関が求めていることではありません。
- 4段階は、データの項目から決まった規則で機械的に決めます。人の判断で上げ下げしません。判定の規則は「データの出典と更新方針」に載せます。
- 施設ページでは、記号の横に名前を文字で表示し、元のデータ（日本語の原文）と出典（医療情報ネット／厚生労働省リスト）も同じ画面に表示します。

### 並び順

- 一覧は、言語の対応の段階の順（◎→○→△→―）に並べます。一覧の上に「対応の段階の高い順に並べています（◎が先頭）」と表示します。
- この並び順は、言語の対応の記録の順で、医療機関の評価や順位ではありません。広告料や医療機関からの依頼で順番は変えません。
- 同じ段階の中は、病院→診療所→歯科診療所の順に並べ、その中は医療機関の名前のアルファベット順（英語名がない場合は日本語名の順）に並べます（現在の実装 lib/data.ts の規則）。

### 正確さのために

- 受診する前に、医療機関へ電話で確認してください。この案内は、すべての施設ページの上部に表示します。報告の内容が古い場合や、担当者が不在の場合があるためです。
- 誤りを見つけた場合は、「情報の訂正・掲載に関する連絡」からお知らせください。確認できた内容は、次の項目のとおり反映します。

### 医療の助言について

このサイトは、病気やけがの診断・治療についての助言をしません。症状から病気を判定する機能も設けません。命に関わる症状がある場合は、すぐに119番に電話してください（→ 救急のページ）。

### 表現のルール

- 医療法と「医療広告ガイドライン」に沿って書きます。使わない言葉（「No.1」「最高」「日本一」「おすすめ」「英語OK」など）を言語ごとに決め、公開前に機械で検査します（→ 03 確認表 運用ルール1）。
- 解説ページ（救急・医療費と保険・受診の流れ・薬局）では特定の医療機関名を書かず、制度の説明には公的機関の出典と確認日を付けます。

## 3. データの出典と更新方針（`/{lang}/data-sources/`）

### 使っているデータ

| データ | 提供元 | 使っている項目 | 時点 |
|---|---|---|---|
| 医療情報ネット（ナビイ） | 厚生労働省（各都道府県が医療機関の報告をもとに公表） | 名称、所在地、診療科、診療日・時間、対応言語と方法、支払方法、救急の体制など | 【変数：取得日・データの基準日】 |
| 外国人患者を受け入れる医療機関のリスト | 厚生労働省・観光庁（都道府県が選出） | 掲載の有無、対応言語と方法（医療通訳者・コーディネーター・遠隔通訳・その他） | 2026年6月30日公表版（2026年9月30日の一部変更まで反映） |
| 多言語の表記 | 厚生労働省・自治体・JNTO などの多言語資料／Unicode CLDR | 診療科・地名（辞書）、言語名・曜日（CLDR） | 訳ごとに出典を記録 |

- 出典の書き方は、厚生労働省の利用条件の例にならい「〇〇（厚生労働省）（URL）を加工して作成」とします（03 確認表 運用ルール6）。
- 【要確認】医療情報ネット（ページ・オープンデータ）の利用条件（クレジット表記の文言、商用利用の可否）を、公開前に原文で確認します。jiro-2 さんの取得元（オープンデータ 2026年6月1日時点）と合わせて確定します。

### 施設ページへの表示

- すべての施設ページに、出典と時点（「医療情報ネット 〇年〇月時点」「厚生労働省リスト 〇年〇月版」）と、そのページの最終更新日を表示します。
- 前回の更新から内容が変わった項目は、「この情報は〇年〇月に変わりました」と表示します（DB の changed_fields）。
- データの時点が180日以上前の施設には「情報が古い可能性があります」と表示します【推測：日数は社内基準案】。

### 4段階の判定規則

医療機関ごと・言語ごとに、次の順で確かめ、最初に当てはまった段階にします。「医療情報ネット」と「厚生労働省リスト」の両方を見ます。

1. 厚生労働省リストの「医療通訳者」または「コーディネーター」の欄に、その言語が書かれている → ◎
   - ただし、欄の内容が電話・タブレットなどの遠隔通訳サービスなら5の○、翻訳機なら6の△として扱います。コーディネーターは、言語が明記されている場合だけ数えます。
2. 厚生労働省リストに、医師がその言語で対応すると書かれている（例：「英語を話せる医師」）→ ◎
   - 筆談・看護師・問診システムでの対応は、医師の対応として数えません。
3. 医療情報ネットで、その言語が「受入可能」になっている → ◎
   - ただし、4言語以上に「受入可能」を付け、翻訳機がある医療機関は、自由記述にその言語と人の対応（通訳・スタッフなど）の両方が書かれている言語だけを◎にします。それ以外の言語は、4〜6の規則で決め、どれにも当たらなければ翻訳機で対応しているとみなして△にします。
4. 厚生労働省リストの「対応できる外国語」に載っているが、対応の方法の記載がない → ◎（厚生労働省リストは、医療機関が「受け入れ可能」として報告した一覧のため）
5. 厚生労働省リストに、電話・ビデオ・映像などの人による遠隔通訳が書かれている → ○
6. 医療情報ネットまたは厚生労働省リストに、翻訳機（音声翻訳機・翻訳アプリ・翻訳タブレットなど）が書かれている → △
   - 「翻訳機なし」「使用していません」などの書き方は、翻訳機ありと数えません。
   - 施設ページには、翻訳機の記録がどちらの出典にあるかを表示します。
7. 上のどれにも当たらない（言語の記載だけがある）→ ―

- 判定に使った根拠（例：「ナビイ:受入可能」「D5:遠隔通訳」「翻訳機あり（ナビイ・D5）」）は、医療機関・言語ごとにデータに記録しています。
- 規則を変えるときは、変える前と後で段階が動いた医療機関・言語の一覧を作り、確認してから反映します。規則を変えた日と内容は、このページに記録します。
- 2026年10月31日：判定規則 v2 を確定しました（人の遠隔通訳を翻訳機と数えない、医師が話すと書かれた言語だけを医師の対応と数える、翻訳機の記述を厚生労働省リストの全ての欄から拾う、など）。

### 更新の頻度

- 医療情報ネットのオープンデータの更新（6月1日・12月1日時点）に合わせて、年2回、全件を取り直します。その間は月1回、一覧だけを取り直して、医療機関の増減を反映します（jiro-2 さんのデータ報告 §6 による）。
- 厚生労働省のリストが改訂されたときは、そのつど反映します。
- 利用者・医療機関から訂正の連絡があった場合は、公的なデータまたは医療機関の公式サイトで確認できたものを反映します。確認できない内容は反映せず、医療機関から都道府県への報告の訂正をお願いします【推測：医療情報ネットの元データは医療機関の報告のため】。

### 検索結果に出すページ

施設の数が少ない地域・診療科の組み合わせのページは、検索エンジンに表示させない設定にしています。情報が少ないページで利用者を迷わせないためです（設計書 §4-2）。

## 4. 情報の訂正・掲載に関する連絡（`/{lang}/contact/`）

### 医療機関の方へ

- 掲載は無料です。掲載の依頼・取り下げ・内容の訂正は、このフォームからご連絡ください。
- 当サイトの情報は医療情報ネットの報告をもとにしています。内容を恒久的に直すには、都道府県への報告の訂正もお願いします。
- 【要決定】掲載の取り下げ依頼に応じるか（公的データの再掲のため、応じない選択肢もある）。

### 利用者の方へ

- 「電話したら対応していなかった」「番号が違った」など、事実の誤りを教えてください。
- 個別の症状や受診先の相談には回答できません。救急の場合は119番、症状の相談は #7119（実施地域のみ）などの公的窓口をご利用ください（→ 救急のページ）。

### フォームの項目

医療機関名／該当ページの URL／誤りの内容／正しい内容と根拠（URL など）／連絡先（任意）／医療機関の関係者かどうか
※フォームの設置先・送信先は【要決定】。運用開始まで、問い合わせへの返信の担当は決めません（外部への連絡は施主の承認後）。

## 5. 免責事項・プライバシーポリシー（要点）

### 免責事項

- このサイトの情報は、公的なデータと医療機関の報告をもとにしています。内容の正確さ・最新であることは保証できません。受診の前に医療機関へ確認してください。
- このサイトは医療の助言をしません。このサイトの情報だけで受診先や治療を決めないでください。
- 掲載している電話番号・金額・制度は、各ページに記載した確認日時点のものです。

### プライバシーポリシー

- アクセス解析ツール【要記入：GA4 等】を使っています。収集する情報、利用目的、無効にする方法を記載します。
- 問い合わせフォームで受け取った情報は、返信と訂正の確認だけに使います。
- 広告を表示する場合は、配信事業者と Cookie の扱いを追記します。
- 【要確認】医療の検索内容（どの言語で、どの診療科を見たか）は健康に関わる情報として扱われる可能性があります。解析ツールに送る項目を、公開前に決めます【推測】。

## 6. tomomi-2 さんに判断をお願いしたいこと

v1 の「1. 一覧の既定の並び順」は、本番の実装（段階の順→施設の種類→名前）に合わせて本文を書いたため、取り下げます。

1. **監修**
   - A：監修者なしのまま出し、「監修」「医師監修」の表記をしない（現在の本番と同じ）
   - B：医師の監修者を探す（費用と外部への連絡が発生するため、MediaXAI さんのご判断が必要）
   - saburo-2 の案は A です。
2. **掲載の取り下げ依頼**
   - A：応じない。公的データの再掲のため、内容の訂正（都道府県への報告の訂正を含む）で対応する
   - B：応じる。依頼があった施設は非表示にする
   - saburo-2 の案は A です。B にすると、公的データにある施設が当サイトだけに無い状態になり、「どの施設が対応しているか」を出典どおりに示すという編集方針と合わなくなるためです。
3. **運営者情報の【要記入】欄**（運営会社・所在地・代表者・設立・法人番号・電話受付の有無・公開日）：MediaXAI さんへの確認をお願いします。

3日たってもご指示がなければ、1・2 とも A で進めます。
